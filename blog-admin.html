新しいブログ記事を追加

入力内容から JSON を生成します。生成結果を blog/blog-data.json の配列に追加してください。



    

      
プレビュー

      

    

  


  

    
使い方

    
    
      
  1. 記事IDを決めます（URL は blog/post.html?id=記事ID になります）。
    2. 
      
  2. フォームに内容を入力し「JSONを生成」を押します。
    3. 
      
  3. 「JSONをコピー」で内容をコピーし、blog/blog-data.json の配列に追加します。
    4. 
      
  4. blog.html を開いて、記事が一覧に出ることを確認します。
    5. 
    

    
注意: 記事IDは重複しないようにしてください。本文はそのまま HTML として表示されるため、信頼できる内容だけを入力してください。
